── 4. 结论（对外口径） ────────────────────────────────────────────────────
1. 本项目 CLI 能在**第三方官方外部靶场 DVWA** 上真检出一个 id@url 注入点，
   3 条技术命中、High、exit 2；官方真值脚本同场 5/5 真值端点全检出、0 误报。
2. 同路径官方 impossible 安全档 CLI 0 命中（187 次请求，阴性可信度 ok）⇒ A/B 成立。
3. 本地网关两条都接进 CLI `--ai-report` 并真实出稿：Ollama 完整（5/5 章审阅 ✅）；
   dsh 只出半成品（未过审、partial=true），**不得宣称 dsh 上 AI 报告已通过**。
   AI 报告成败不影响扫描结论（D205 语义），两次扫描结论逐字一致。
4. 两次扫描都如实披露覆盖缺口：path / forms 两注入面**按当前配置没测**，
   只测了 1 个注入面（id@url）。**不得把本次结果外推成「全局检出率」**。
5. 没有自建靶场、没有 mock 自证、没有放宽任何判据；所有数字可复现（见上命令 + 落盘 JSON）。
