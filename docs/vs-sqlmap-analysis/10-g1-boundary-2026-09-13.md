# 10-g1-boundary-2026-09-13.md — G1 闭环：boundary×payload 接线（兼容族排序）

> 复盘：07-remnant-gaps-2026-09.md 的 G1「boundary→payload 未接线（笛卡尔积缺失）」
> 本轮落地。2026-09-13 实测基线：server 全量单元 + e2e 检测回归（19 PASS / 0 FAIL）。

## 一、问题确认（读代码核实，非照搬旧文）

- `probeBoundary`（Detector.js）探出的闭合前缀存入 `point.boundary`，历史上只有两个消费点：
  1. BooleanBlindDetector：作为**唯一一对**「boundary 感知真伪对」（`{boundary} AND 1=1/1=2-- -`）；
  2. UnionDetector：传给 `discoverEchoColumnsDetailed` 拼 UNION 探针。
- 注册表条目自带 `boundary` 元数据（声明模板适用的闭合引号形态），但 **selectPayloads 的
  boundary 参数零消费者**（Boolean/Error/Time 三处 registry 路径均未传）→ 检测器按声明顺序
  **全量盲发所有闭合族变体**：
  - Boolean 主轮命中即 break → 无关族变体浪费请求；
  - Error/Time 在探测被拦/熔断场景下，兼容族与无关族混排、结果顺序不可预期。
- TimeBlindDetector 已有 [real-MySQL FIX 2026-09-07]「上下文选族重排」先例（正则粗判，
  `'`/`"` 混为一谈，且仅 Time 有）——G1 是把它推广为通用机制。

## 二、落地（排序而非硬过滤——与 sqlmap 的关键差异）

新增 `orderEntriesByBoundary(entries, boundary)`（payloadRegistry.js）：

- **兼容单位 = 引号族**（`'` / `"` / `` ` ``），非精确前缀：模板仅内嵌最小闭合引号且自平衡，
  单引号族条目对 `')` / `'))` / `%'` / `%')` 等一切单引号系上下文语法有效（实测依据 Time
  FIX 同思路）；取探测前缀中首个引号字符判族，`%`（LIKE）与 `\`（转义）不计入。
- **稳定排序**：兼容族条目整体前置（保相对序），无关族跟后。输入 <2 / 族不可判定 /
  全兼容 / 全不兼容 → 原样返回。
- **不做硬过滤**（刻意为之）：probeBoundary 在 WAF 拦探测 payload 时回退空串，硬过滤会让
  「探测被拦 → boundary 误判」灭绝对应闭合族全部变体 → 漏检。排序保证早命中省请求、
  误判时全集仍在（零回归）。

接入三处（均传 `ctx.point?.boundary`）：
- BooleanBlindDetector._getBooleanPairs（registry 路径）——主轮 break 早退直接兑现收益
- ErrorDetector._resolveErrorTemplates（registry 路径）——全池扫描时兼容族先出结果
- TimeBlindDetector._resolveTimeTemplates（registry 路径）——与既有选族重排互补（元数据级
  排序先落位、正则重排兜底，不改 Time 既有行为）

## 三、验证

- 新增 `tests/payloadRegistry.boundaryOrder.test.js`（6 用例）：族判定 / 括号·通配符前缀 /
  空串·反斜杠原样 / 全兼容·全不兼容·单条原样 / 真实注册表端到端（置前 + 全集不丢）。
- 零回归：Boolean/Error/Time/payloadRegistry 既有测试、e2e 检测回归 19 PASS / 0 FAIL、
  server 全量。

## 四、与 sqlmap 的差距说明（剩余）

sqlmap 是 boundaries.xml × payloads/*.xml **逐条**笛卡尔积 + boundary 级 level 门；
本实现是「探测固定 13 候选（高频短路）+ 兼容族排序全集投递」。差异：
- 探测成本固定 13 请求（sqlmap 按 level 分档、默认档更少）——本工具探测含高频短路，
  低 level 场景额外成本约 6-13 请求/点，换取 WAF 误判零回归；
- 全集投递而非逐条相称（不会因闭合形态不同跳过载荷族）——覆盖率 ≥ sqlmap 默认档，成本略高。
- 若未来需要 sqlmap 等价的「boundary 级 level 门」，可在探测候选表上按 level 截断并
  **以 opt-in 配置**打开（默认关，避免行为漂移），并配套靶场回归。
