# 服务端类型化档案（checkJs → strictNullChecks）

> 状态：**已完成**。`server/tsconfig.json` 已启用 `checkJs` + `strictNullChecks` + `strictFunctionTypes`，
> `tsc -p server/tsconfig.json` **0 错误**，并已接入 CI（`.github/workflows/ci.yml` 的 lint job）。

## 为什么做

服务端此前**零类型覆盖**——`tsconfig.json` 的 `include` 只有前端 `src`，
几万行 server JS 没有任何静态检查，重构没有安全网。前端是 `strict: true`，后端裸奔。

## 两阶段的收敛轨迹

| 阶段 | 基线 | 收尾 | 说明 |
|---|---|---|---|
| ① `checkJs`（基础检查） | 110 处 | **0** | 见下方「批量打根因」 |
| ② `strictNullChecks`（null 安全） | 83 处 | **0** | 见下方「真问题」 |

回归：全量单测 **1768 条 / 0 失败**。

## 批量打根因（阶段① 的做法）

110 处只用了 17 批编辑——关键是**先找"被引用最多、但缺声明"的点**，而不是逐个 error 改：

| 修复 | 编辑数 | 消除 |
|---|---|---|
| `models.js` 补 `Target`/`InjectionPoint`/`DetectionResult` 三个 `@typedef` | 1 | 12 |
| `models.js` 三个工厂函数补 `@returns` | 1 | 5+ |
| `Detector` 基类 `detect` 补 `@returns`（原推断为 `Promise<never>`） | 1 | 9 |
| `Extractor` 状态对象加 `@type` | 1 | 8 |
| `clampTimeVars` 返回类型 + `ctxBase` 字段 | 1 | 11 |

**规律**：类型缺失会连锁放大——基类抽象方法漏一个返回类型 → 9 个子类实现全报错；
models 漏 typedef → 19 处引用全报错。

## strictNullChecks 修掉的典型真问题

- `s.codePointAt(i)` → `number | undefined`，此前直接参与位运算与比较
- `this._server.close(resolve)` → 闭包内 `_server` 可能已被置 null
- `new URL(current.headers.location, ...)` → 多值响应头下是 `string[]`
- `headers['Authorization'] = rp.header` → digest 重放头可能为 null
- `cache.get(key)` / `sharedBaseline?.status` → 未收窄就参与运算

## 后续档位（逐个评估，未启用）

| 开关 | 代价 | 决策 |
|---|---|---|
| `strictFunctionTypes` | 0 处 | ✅ 已启用 |
| `noImplicitThis` | 11 处 | ⏸ 报错集中在 Exploiter 的 3 个模块级函数（`udfInstall`/`regRead`/`registryWrite` 用 `this.extractor`，由实例 `.call(this,...)` 调用）。JSDoc `@this` 对**函数声明**不生效，正解是改造成类方法 → 与「拆上帝对象」一并做 |
| `noImplicitAny` | 3045 处 | ⏸ 给每个函数参数补类型，体力活 |

**为什么逐项启用而不是 `"strict": true`**：整体开启一次引入 3047 处，其中 1925 处是隐式 any
的体力活，会把真正有价值的 null 检查淹没。

## 修法速查（供后续档位复用）

- `string | null` 传给 `string` 形参 → `String(x)` 收窄，或断言 `/** @type {string} */ (x)`
- `Object is possibly null` → 可选链 `?.`（语义允许时），或闭包内先取局部变量
- `new Promise()` 缺 executor 形参类型（TS2810）→ 给 `resolve` 传显式实参 `resolve(undefined)`
- 空数组字面量被推断为 `never[]` → 给容器加 `/** @type {T[]} */`
- `@type {{...}|null}` 标注 `let x = null` 可能仍被推断为 `null` → 改 `any` 或规范多行 JSDoc 块
- **批量替换的匹配串必须含足够上下文、替换数必须为 1**
  （曾因正则过宽切断 JSDoc 描述句，错误数从 19 涨到 28；也曾因 JSDoc 里写 `@@name` 触发 TS1003）
