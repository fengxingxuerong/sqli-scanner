### 3.4 WAF 对抗

- **228 tamper**（sqlmap 官方全集）+ 算子替换族 + 拦截证据驱动的自适应重跑（≤2 轮）
- 62 家 WAF 指纹 + 推荐链
- 实测：ModSecurity CRS 4.1.0 开启状态下 5/5 场景 / 11 技术位命中，安全对照零误拦
- **诚实边界**：真实云 WAF（安全狗/阿里云/Cloudflare）未实测，报告不夸大

### 3.5 合规与安全设计（攻击工具自防御）

scope 授权逐跳硬约束（302 圈外拒发）· SSRF 分层 + DNS 钉死防 rebinding · 凭据全链路打码 · API token 恒时比较 · 非 root 容器 · 默认限速 10 req/s（防“一键打挂脆弱目标”）· 阴性结论输出 `inconclusive` 而非“安全” · dbmsEvidence 证据分层落盘

## 6. 快速上手

```powershell
# Web UI
cd server; node index.js          # → http://127.0.0.1:8747

# CLI 常用
node server/bin/cli.js -u "http://target/item?id=1" --dbms MySQL --level 3 --dbs
node server/bin/cli.js -u <url> --dump -D sqli_lab -T users
node server/bin/cli.js -u <url> --csrf-url http://target/login --csrf-token csrf_token

# 全量验证（需要本机 MySQL:3306 / PG:5432 / MSSQL:65039）
node e2e/run-all.mjs
```

## 7. 已知边界（如实声明，不做虚假承诺）

1. **9 个 template-only 库**（TiDB/DM8/ClickHouse 等）：无真机验证，报告自动带“待复核线索”caveat。Oracle 已于 09-15 真机验证（本机静默安装 + oracledb thin，无 Docker/Instant Client）。
2. **真实云 WAF**：CRS 实测通过不外推到安全狗/阿里云/Cloudflare；上线前建议按 pentest-lab 方法论做一轮真实 A/B。
3. **os-pwn / meterpreter**：设计上不做（超出工具合规边界）。
4. **MySQL 8 默认配置下 fileRead 不可用**：`secure_file_priv=NULL` 是数据库合规默认值，非引擎缺陷。
5. **NTLMv2 / Kerberos**：NTLM 已接（HttpClient 三步握手 + DES 自实现）；Negotiate/Kerberos 未支持。

## 8. 运维与复现要点

- 本机依赖启动：MySQL `D:\mysql\bin\mysqld.exe --defaults-file=D:\tmp-sqlilab\my.ini --console`（root/root）；PG 用低权账号 `CodexSandboxOffline`（密码 sandbox）启动 `D:\pg-smoke\bin\bin\postgres.exe -D D:\pg-smoke\data`；MSSQL 服务 `MSSQL$SQLI`（sa / SqLi_2026_T! @ 127.0.0.1:65039）；Oracle 服务 `OracleServiceFREE`（SYS / SqLi_2026_0! @ 127.0.0.1:1521/FREEPDB1）。
- redteam-lab 由 `run-with-env.mjs` 自管靶场生命周期；先独立拉起 MySQL 再跑 run-all 可避免 env.mjs 退出连带杀库。
